# Frontend Engineering Sandbox

This repository serves as my personal coding sandbox and learning ledger. It contains the practice code, mini-projects, and isolated concept tests I built to master frontend fundamentals and advanced state management before building my larger, full-stack applications.

## 📂 Repository Structure

* **`/HTML` & `/CSS`**: Foundational layout practices, responsive design techniques, CSS Grid/Flexbox, and mini-projects like dark-mode toggles and styled landing pages.
* **`/JAVASCRIPT`**: Deep dives into core JavaScript mechanics. Includes isolated practices on:
  * Closures and Lexical Scoping
  * Asynchronous JS (Promises, Async/Await)
  * Event Delegation and Bubbling
  * Polyfills and advanced functions
* **`/react-practice`**: Foundational React concepts including hooks (`useState`, `useEffect`, `useReducer`), Context API, and component lifecycle.
* **`/redux-async-practice` & `/redux-todo`**: Advanced state management practice focusing on Redux Toolkit, complex store configurations, and handling asynchronous API data flows.

## 🚀 Purpose
Rather than relying solely on tutorials, I use this sandbox to break down complex UI/UX challenges and JavaScript behaviors in isolation. This approach ensures I have a strong, practical grasp of the underlying technologies that power modern web development.
